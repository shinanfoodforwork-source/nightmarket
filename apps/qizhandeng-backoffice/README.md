# 七盞燈｜供應鏈後勤營運系統 網站版 v1

此版本將既有 Google Sheets「05_供應鏈後勤營運系統_主控表」轉為可在手機與電腦操作的 Google Apps Script Web App。

## v1 已涵蓋
- 中文後勤導覽
- 手機 / 電腦響應式介面
- 營運儀表板
- 客戶、供應商、商品、倉庫、訂單、採購、入庫、庫存、配送、簽收、異常、對帳等模組
- 搜尋與分頁
- 新增 / 編輯 / 作廢
- 唯讀模組保護
- 稽核紀錄
- 直接讀寫既有 Google Sheets

## 後勤主流程
客戶下單 → 庫存判斷 → 採購 → 入庫驗收 → 庫存 → 揀貨 → 配送 → 簽收 → 對帳損益 → 異常處理 → 稽核

## 部署方式
1. 建立 Google Apps Script 專案。
2. 建立 `Code.gs` 並貼入本資料夾的 `Code.gs`。
3. 新增 HTML 檔案，名稱設為 `Index`，貼入 `Index.html`。
4. 在 Apps Script 專案設定中顯示 `appsscript.json`，覆蓋本資料夾內容。
5. 部署 → 新增部署 → 網頁應用程式。
6. 執行身分建議選「我」。
7. 後勤系統建議限制公司內部或指定帳號存取，不建議直接公開給所有人。
